精选案例Case Studies

CASE 01 · 旗舰案例

AI 驱动的 B2B 增长体系 0–1

杭州新天元织造 · ZARA / MUJI / HUGO BOSS / M&S 等 30+ 品牌面料供应商（曾合作优衣库）· 年销售额 4–5 亿

2023.10 — 至今
挑战 CHALLENGE

一家深耕线下渠道的传统纺织制造企业，数字化基础薄弱：入职前获客仅靠展会与陌拜，线上获客为零；竞品监控、线索录入、周报生成全部依赖人工，运营被盯盘和表格吞没；展会带回的名片和照片，转身就躺进了相册和群聊。

方案 APPROACH

以 「AI 做提取，Agent 做判断，人做决策」 为核心设计原则，分三层搭建增长体系：

壹增长引擎层 · 内容与双轮驱动

  • 多方向内容测试（面料细节 / 应用场景 / 趋势穿搭 / 工厂实拍），锁定「产品推荐」核心获客方向，沉淀 5 大内容专栏，覆盖小红书 / 视频号 / 公众号 / 抖音
  • 双轮驱动模型：小红书付费投流拿下规模化增量市场；微信体系员工转发撬动社交杠杆，零成本触达存量市场

贰数据与转化层 · 漏斗与归因

  • 搭建「开口 → 留资 → 加微 → 登记」四级漏斗日报体系，数据问题当日发现、当日处理
  • 按周迭代素材 ROI 排名、动态调整预算；按月全链路成本归因，定位转化瓶颈
  • 建立线索分级与销售承接 SOP；协同 IT 从 0–1 搭建 CRM；主导钉钉知识库建设（5 大系列 + 80 个 Base 产品体系）赋能销售

叁AI 基建层 · 多 Agent 营销自动化体系

  • 多 Agent 协同：基于 Coze Agent + 云手机搭建分工智能体 —— 竞品监控 Agent 自动采集 22 个竞品账号并按周期输出报告；运营周报 Agent 整合账号 / 投放 / 线索转化数据，自动生成周报与优化建议
  • MCP 打通自建 CRM：落地「截图识别 → 线索录入 → 人工审核 → 自动创建」流程并封装为可复用 Skill；支持每日定时拉取线索、按月 / 季度分析流转数据；关键判断保留原图与人工复核口，避免 AI 黑盒
  • 钉钉 AI 表格协同：承载选题、文案、标题、发布进度全流程管理；自动化流程对异常数据「条件分支 → AI 诊断 → 钉钉提醒」，把散落在群聊、相册、Excel 里的线索与周报，变成团队可查询、可复核、可自动流转的行动清单

方法论Methodology

Agent 驱动运营闭环

让数据采集、异常预警、深度分析在 Agent 内自动流转，运营经验持续沉淀回智能体，人只保留判断与决策。

数据采集 → 异常预警 → 深度分析
→ 结论回填 → 执行反馈

双轮驱动获客模型

付费投流做规模化增量，社交裂变做零成本存量，两条链路各自优化转化效率，以获客效果反哺品牌认知。

付费投流（增量）× 社交裂变（存量）

隐性知识显性化

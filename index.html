方案 APPROACH

不是先选工具、再寻找应用场景；而是先拆解内容、投放、承接与复盘中的重复工作，再逐一判断：交给生成式 AI、Agent、自动化规则，还是保留人工决策。

壹内容层 · 策略、生产与分发

  • 用多方向测试锁定「产品推荐」核心获客方向，沉淀 5 大内容专栏；小红书付费投放获取增量，微信员工转发触达存量客户。
  • 用钉钉 AI 表格统一选题、标题、正文、排期和分发；Style3D、AI 图像工具与剪映模板负责素材生产，单条内容交付由 3–5 天缩短至 3–5 小时。

贰数据层 · 漏斗与归因

  • 建立「开口 → 留资 → 加微 → 登记」四级漏斗：登记成本 ≥400 元 / 人为高危，250–400 元为关注，低于 250 元为正常；按周追踪素材 ROI、按月归因全链路成本。
  • 协同 IT 从 0–1 搭建 CRM，补上线索分级、销售承接 SOP 与转化统计，让线上获客从线索产生一直追踪到成交。

叁AI 基础层 · 分析型与执行型 Agent

  • Coze Agent 多任务角色：在同一 Agent 内分工完成竞品监控、投放分析与周期复盘，共享任务记忆和历史上下文，自动生成周报与建议。
  • 桌面 Agent：可用 Codex、TRAE Work、Workbuddy、千问办公等完成后台导出、解析写表，并通过 MCP 连接 TYTX，完成线索识别、建档与每日 / 每周 / 每月进度管理；关键字段保留人工复核。
  • 两张钉钉 AI 表格：内容管理表承接内容协作，投放监控表承接数据与诊断；表内 AI 字段和自动化规则提供辅助，不把所有自动化都包装成 Agent。

业务落地 · FROM SYSTEM TO WORKFLOW

内容端 · CONTENT HUB

一张表承接整个内容协同

用钉钉 AI 表格统一管理选题、内容分类、标题、正文、发布平台、排期与进度，并通过 AI 字段辅助生成朋友圈文案，打通策划、生产、协同与分发。

它不是素材清单，而是内容项目的协同中枢。

投放端 · FEEDBACK LOOP

投放监控表形成一个有反馈的小闭环

桌面 Agent 先把聚光后台的每日数据导出、解析并写入表格；此后汇总、分档、诊断和结果回流由表内规则与 AI 辅助完成。

数据先入表，规则先判断，AI 辅助诊断，人确认动作，结果持续回流。

表内自动化

条件分支负责判断，AI 给出辅助建议

自动化流程按预设阈值识别风险档位，生成诊断记录并发送提醒；是否调整素材、预算或承接动作，仍由人结合业务情况确认。

承接端 · CRM

桌面 Agent 负责操作，人保留复核

通过 MCP 连接公司自建 CRM，完成截图识别、字段提取、录入和建档；原图与关键字段保留人工复核口，后续线索进度继续沉淀为日报、周报与月报。

执行型 Agent 具备环境可替换性：同一流程可迁移至 Codex、WorkBuddy、Trae Work、千问办公、豆包工作等桌面 Agent 方案。

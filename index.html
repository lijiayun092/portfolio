CASE 01 · 旗舰案例

AI 驱动的 B2B 增长体系 0–1

杭州新天元色纺 · 全球色纺面料领军企业 · 20 年色纺大厂 · 国家高新技术企业 · 年销售额 4–5 亿

2023.10 — 至今
挑战 CHALLENGE

一家深耕线下渠道的传统面料企业，数字化基础薄弱：入职前获客仅靠每年 2 场线下展会（单场成本 80–100 万）与陌拜，线上获客为零；展会带回的名片和资料没有存档、不可追踪——很多客户会后即彻底断联，断联就是最大的损失。竞品监控、线索录入、周报生成全部依赖人工，运营被盯盘和表格吞没。

方案 APPROACH

以 「AI 做提取，Agent 做分析，人做决策」 为核心设计原则 —— Agent 深度介入工作流：不只跑腿执行，更要完成诊断分析、输出结论与建议；而预算创建与策略调整，始终由人做最终决策 —— 分三层搭建增长体系：

壹增长引擎层 · 内容与双轮驱动

  • 多方向内容测试（面料细节 / 应用场景 / 趋势穿搭 / 工厂实拍），锁定「产品推荐」核心获客方向，沉淀 5 大内容专栏，覆盖小红书 / 视频号 / 公众号 / 抖音
  • 双轮驱动模型：小红书付费投流拿下规模化增量市场；微信体系员工转发撬动社交杠杆，零成本触达存量市场

贰数据与转化层 · 漏斗与归因

  • 搭建「开口 → 留资 → 加微 → 登记」四级漏斗日报体系，预设风险阈值自动预警（登记成本 ≥400 元/人、CPL 250 元/人），数据问题当日发现、当日处理
  • 按周迭代素材 ROI 排名、动态调整预算；按月全链路成本归因，定位转化瓶颈
  • 建立线索分级与销售承接 SOP；协同 IT 从 0–1 搭建 CRM；主导钉钉知识库建设（5 大系列 + 80 个 Base 产品体系）赋能销售
  • 转化端不止于「交接即止」：两次全量销售统计把每个人的拉单与转化数据透明化呈现——不为排位，而为让组织第一次看见数据的价值；并在汇报中点破核心命题：线上获客客户与传统大客户的承接模型不同，销售的能力模型必须随之改变

叁AI 基建层 · 多 Agent 营销自动化体系

  • 多 Agent 协同：在扣子（Coze）平台上分化多个角色分身协同作业 —— 竞品监控 Agent 经云手机自动采集 22 个竞品账号并按周期输出竞品周报；运营周报 Agent 整合账号 / 投放 / 线索转化数据，自动生成周报与优化建议
  • MCP 打通自建 CRM：落地「截图识别 → 线索录入 → 人工审核 → 自动创建」流程并封装为可复用 Skill；支持每日定时拉取线索、按月 / 季度分析流转数据；关键判断保留原图与人工复核口，避免 AI 黑盒
  • 钉钉 AI 表格 × Agent：把两张 AI 表格（内容管理 × 投放监控）当作数据库，Agent 直接读取与写入；自动化流程对异常数据「条件分支 → AI 诊断 → 钉钉提醒」，把散落在群聊、相册、Excel 里的线索与数据，变成团队可查询、可复核、可自动流转的行动清单

整套体系按 loop 而非职能搭建：内容、投放、承接、复盘 4 个端口、10 余个环节，80–90% 的工作在同一条主 loop 内自闭环完成；专业门槛环节（如聚光官方投手）外部协作，而数据层始终自己掌握——没有数据层，就无法归因。
